# Ход действий (обновлено 09.11.2026)

## 1. Фильм S2 — перезалить как ДЛИННОЕ видео

**Почему он стал шортсом.** Вертикальный ролик до 3 минут YouTube автоматически отправляет в Shorts.

**Решение — горизонталь 16:9 без обрезки.**
- Кадр стоит целиком.
- Бока расширены продолжением сцены.
- Слева идут названия глав.
- В конце — заставка 20 с под конечные элементы.

**Что сделать:**
```
python3 -I tools/longform/to_long.py s2/out/kurer_s2_film.mp4 s2/longform/kurer_s2_long_4k.mp4 --4k --chapters s2/longform/chapters.json
```
Всё для загрузки — в `s2/longform/ZAGRUZKA_S2_DLINNOE.md`: название, описание с главами, теги, настройки, конечная заставка, закреплённый комментарий.

Старый шорт можно оставить. Но лучше скрыть его в «Доступ по ссылке» на время теста, чтобы два ролика с одним материалом не конкурировали.
